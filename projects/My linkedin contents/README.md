# My LinkedIn Contents

- Description: LinkedIn content automation, built on the WAT framework (workflows, agents, tools).
- Status: active.
- Key dates: support the goal of 50 clients before 2026-12-31.

## Structure

- `workflows/linkedin-content.md`: the SOP for drafting and posting LinkedIn content.
- `tools/linkedin.py`: posts text updates to LinkedIn via the official API.
- `.env`: LinkedIn API credentials. Never commit this file.
- `.tmp/`: disposable temp files. Gitignored.
- `wat-architecture.md`: the full WAT framework guide.
