## Page Purpose

The homepage for **Travel Case**, a full-service travel booking website (flights, hotels, cars, transfers/insurance). This is a public marketing + search entry page — the visitor hasn't logged in yet. Goal: get them searching within seconds, while the page still reads as a trustworthy, established travel brand rather than a startup landing page.

## Brand System (apply consistently)

- **Colors:** Navy `#0B2545` (primary/header), Navy Dark `#123063` (gradient partner), Steel Blue `#3A6EA5` (secondary/links), Gold `#C9A24B` (CTA/accent only — never a large fill), Gold Dark `#A9823A` (hover), Neutral background `#EDEFF2`, Card white `#FFFFFF`, Ink text `#1B2033`, Slate muted text `#5C6470`, Border `#DCE1E8`.
- **Typography:** Headings/prices in **Space Grotesk** (semibold/bold). Body/UI text in **Inter** (regular/medium).
- **Logo:** icon + wordmark lockup — a hairline gold outline suitcase icon (no fill, single stroke weight, rounded corners) inside a navy rounded-square badge, next to the "Travel Case" wordmark in Space Grotesk bold navy (or white on dark backgrounds).
- **Visual tone:** trustworthy, corporate, understated. Rounded corners (10–16px on cards, 8px on inputs). Soft low-opacity navy-tinted shadows, not harsh drop shadows. No purple/violet gradients, no glassmorphism, no generic "AI startup" look.

## Page Structure

**1. Header / navigation bar** (navy background, full width)
- Logo lockup on the left.
- Center nav links: Explore, Flights, Hotels, Cars.
- Right side: language/currency selector (e.g. "EN · NGN"), a "Log in" outline button, and a solid gold "Agent portal" button for B2B users to self-identify and switch context.

**2. Hero section** (navy-to-navy-dark gradient background, full width, generous vertical padding)
- Headline (large, Space Grotesk): something like "Every trip, one trusted case." — confident, short, not cutesy.
- Subheading (smaller, Inter, muted light color): one line reinforcing the unified-booking value prop (flights + hotels + cars compared and booked together).
- **Vertical tab switcher** sitting directly above the search card, styled like folder tabs: Flights / Hotels / Cars / Activities / Transfers, active tab visually connects to the card below it (white background matching the card, inactive tabs are translucent on the navy hero).
- **Search card** (white, floating, rounded corners, drop shadow) containing:
  - Trip-type radio row: Round trip / One way / Multi-city
  - A row of fields: From (with airport code + full name as secondary text), a circular swap icon button between From/To, To, Depart date, Return date
  - A gold "Search" button, full height of the input row, right-aligned

**3. "Popular this month" section** (sits partly overlapping the bottom of the hero, white/neutral background)
- Section title in Space Grotesk.
- A 4-column card grid of destinations, each card: a gradient image placeholder, destination name, and a starting price line (e.g. "Flights from ₦410,000 round trip").

**4. "Why Travel Case" trust section**
- Section title.
- A single wide card (or 3-column row) with three short value props, each with a bold title and one-line description: live real-time pricing, one cart/one checkout for multi-vertical trips, agent trade pricing available for registered travel agents.

**5. Footer**
- Standard website footer: logo mark (small), 3–4 link columns (Company, Support, Legal, For Agents), copyright line, and small print noting currencies/markets served.

## Content Notes

- Use realistic Nigerian/West African + international example content (Lagos as a common origin, NGN as the primary displayed currency, with routes to Dubai, London, Nairobi, Bali, Accra as example destinations) rather than generic US-only placeholder content.
- This is a real product for a Sabre-integrated OTA — keep copy grounded and confident, not hypey or exclamation-heavy.

## What NOT to Do

- No purple/violet gradients or neon accents.
- No large gold background fills — gold is for buttons/small accents only.
- Don't make the hero feel like a SaaS product landing page (no floating 3D illustrations, no abstract blob shapes) — this should feel like a travel booking site first.
